## О проекте

**Field Notes** — небольшой демонстрационный репозиторий, оформленный как цифровой блокнот. Здесь нет приложения для установки: весь материал находится в этом README.

Идея проста: фиксировать контекст, описывать наблюдения и оставлять понятный следующий шаг. Хорошая заметка полезнее потерянной идеи.

| Раздел | Что записывать |
| :--- | :--- |
| 💡 Идеи | Вопросы, гипотезы и направления для исследования |
| 🧪 Эксперименты | Что проверяли, как проверяли и что получилось |
| 📝 Наблюдения | Детали, которые стоит сохранить для будущего |
| 🧭 Следующие шаги | Одно конкретное действие вместо длинного списка обещаний |

## Как пользоваться

1. Откройте README и выберите тему заметки.
2. Запишите цель, контекст и наблюдения.
3. Отделите подтверждённый результат от предположений.
4. Сохраните изменения с понятным сообщением коммита.

> **Принцип блокнота:** меньше лишнего оформления в заметках, больше ясности в содержании.

## Пример заметки

### Первая страница

**Цель:** проверить, насколько удобно читать небольшой проект прямо на главной странице репозитория.

**Подход:** краткое описание, таблица разделов, иллюстрация и один законченный пример.

**Наблюдение:** README может быть самостоятельным документом, если читателю сразу понятно, что перед ним и как этим пользоваться.

**Следующий шаг:** заменить демонстрационный материал собственными заметками.
